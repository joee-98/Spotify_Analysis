Spotify Data Cleaning using Python

Overview  
This notebook focuses on cleaning and preparing the Spotify dataset for analysis. The goal is to make the data structured, consistent, and ready for SQL-based analysis.

---

Dataset  
The dataset contains information about Spotify tracks including track name, artist, genre, popularity, duration, and audio features.

---

Objective  
To clean the dataset by removing invalid records and fixing inconsistencies so it can be used for further analysis.

---

Data Cleaning Steps  

- Changed datatypes to ensure proper formatting  
- Removed unwanted columns to simplify the dataset  
- Removed null values to avoid issues in analysis  
- Removed outliers to prevent skewed results  
- Removed duplicate records to maintain accuracy  
- Removed whitespaces to ensure consistency  
- Standardized rows for better processing  

---

Outcome  
The dataset was cleaned and transformed into a structured format suitable for SQL-based analysis.

---

Tools Used  
- Python  
- Pandas  
- Jupyter Notebook

Next Step  
The cleaned dataset is used for SQL analysis to derive business insights.

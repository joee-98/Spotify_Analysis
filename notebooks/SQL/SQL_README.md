# Spotify Data Analysis using SQL

## Overview

This SQL file focuses on analyzing the cleaned Spotify dataset to identify
patterns and trends in song popularity, genres, artists, and audio features.

---

## Dataset

The dataset contains information about Spotify tracks including track
name, artist, genre, popularity, duration, and audio features such as
energy, danceability, valence, and liveness.

The analysis uses the cleaned dataset generated during the Python data
cleaning step.

---

## Objective

To analyze the cleaned Spotify dataset using SQL and derive insights
about song popularity, artist performance, genre trends, collaborations,
and audio features.

---

## Analysis Performed

- Analyzed the most popular artists and tracks
- Compared popularity across different genres
- Studied the relationship between audio features and popularity
- Compared explicit and non-explicit songs
- Analyzed song duration across genres
- Identified highly energetic and highly danceable tracks
- Studied collaborations among popular songs
- Calculated the percentage of hit songs
- Analyzed the contribution of genres and artists to total popularity
- Segmented songs based on energy, valence, and popularity
- Used correlation and window functions for deeper analysis

---

## SQL Concepts Used

- SELECT and WHERE
- GROUP BY and ORDER BY
- Aggregate functions such as COUNT, SUM, AVG, and ROUND
- CASE statements
- Subqueries
- Window functions
- Common table expressions
- NTILE
- Percentage calculations
- Correlation analysis

---

## Outcome

The cleaned dataset was analyzed using SQL to identify patterns in Spotify
songs and understand how popularity varies across artists, genres, and
different audio characteristics.
